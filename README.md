# Like-Flex
OOP C++ assignment for student evaluation kind of like FLEX! It reads data from a file, calculates statistics (max, min, avg), searches students by keyword, and sorts them by total marks. 
Learned a lot about dynamic memory, file handling, and OOP! 

 Features:
✔️ Reads student data from a file
✔️ Calculates max, min, and average marks
✔️ Searches students by roll number or name
✔️ Sorts students by total marks
